## Bi-Directional Community DD Repository
**Status:** ✅ Built (Ready to integrate)

Created a comprehensive due diligence feature:

### Backend (dd_repository.py)
- SQLite database with tables: dd_posts, dd_votes, dd_comments
- CRUD operations for DD posts
- Vote tracking system (upvote/downvote)
- Reddit import functionality from r/pennyprospectors
- Symbol extraction from Reddit post titles
- API endpoints at `/api/dd/*`

### Frontend (DDRepository.jsx)
- View DD posts by symbol or all posts
- Submit DD with flair selection:
  - Fundamental Analysis
  - Technical Analysis
  - Geology/Exploration
  - Catalyst/Event
  - Bullish Thesis
  - Bearish Thesis
- Vote on posts (upvote/downvote)
- Cross-post to Reddit with one click
- View Reddit-imported posts
- Verification badges for quality posts

### Key Features
- Bi-directional: OreTrack → Reddit, Reddit → OreTrack
- Flair system for categorization
- Engagement tracking (views, votes)
- Source tracking (OreTrack vs Reddit)
