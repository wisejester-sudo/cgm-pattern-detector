## KELLY CRITERION ANALYSIS

### Optimal Position Sizing

**Inputs**:
- Probability of success (p): 55% (Good + Great + Filo-tier)
- Payoff multiple (b): 7.0x (net profit)
- Probability of loss (q): 45%

**Full Kelly Formula**:
```
f* = (bp - q) / b
f* = (7.0 × 0.55 - 0.45) / 7.0
f* = (3.85 - 0.45) / 7.0
f* = 3.40 / 7.0
f* = 0.486 or 48.6%
```
